Lumary Ring Designer

Design an effect for the accent ring, name it, and push it to one of the fixture's ten slots. The preview runs the firmware's own renderer, so what you see here is what the ceiling does.

This preview does not flatter. It applies the same gamma curve and the same 8-bit output limit the fixture has, so an effect that collapses at low brightness collapses here too. That is deliberate: you cannot watch the ceiling while you design, so this is the only place to find it.
